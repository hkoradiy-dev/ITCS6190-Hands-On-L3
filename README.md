# ITCS 6190 Hands-On L3

## Overview

This hands-on demonstrates how to build and run a multi-container
microservice application using Docker and Docker Compose.

The application consists of:

- A Python Flask web application
- A Redis cache

## Technologies Used

- Docker
- Docker Compose
- Python
- Flask
- Redis
